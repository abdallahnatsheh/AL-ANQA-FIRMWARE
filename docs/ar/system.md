# System

إعدادات الجهاز والأدوات اليومية. لكلٍّ صفحته (على اليسار) بكامل التفاصيل.

## كرة التتبّع ولوحة المفاتيح

عند المِحثّ تحرّك كرة التتبّع المؤشّرَ وتتصفّح السجلّ؛ وفي التطبيقات تتنقّل وتحدّد. المرجع الكامل: **[لوحة المفاتيح]({{ site.baseurl }}/keyboard)**.

## أيقونات شريط الحالة

| الأيقونة | الألوان | المعنى |
|------|---------|---------|
| `[ANQA]` | سماوي | اسم البرنامج (مع `+` على T-Deck Plus) |
| الدرع | رمادي / أخضر ✓ / أصفر / أحمر | wguard: متوقّف / لا تهديدات / تحذيرات / حرج |
| القمر الصناعي | رمادي / أصفر / أخضر | GPS: متوقّف / يبحث / مثبَّت |
| ᛒ | رمادي / سماوي | Bluetooth: متوقّف / نشط |
| البطارية | أحمر / أصفر / أخضر | مستوى الشحن |

> **ملاحظة عتاد:** `tone()` لا يعمل على هذا اللوح — كل الصوت يستخدم `i2s_driver_install()`.
