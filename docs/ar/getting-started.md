# دليل البدء

> يأخذك هذا الدليل من جهاز T-Deck حديث التهيئة إلى أوّل عملية مسح تُجريها؛ إذ يغطّي تنزيل البرنامج (Flash)، وإعداد بطاقة SD، والتنقّل داخل واجهة الأوامر، وأوّل الأوامر التي ينبغي تشغيلها. لن يستغرق الأمر أكثر من عشر دقائق.

---

## ما الذي تحتاج إليه

| البند | ملاحظات |
|------|-------|
| جهاز LilyGo T-Deck أو T-Deck Plus | تُضيف نسخة Plus وحدة GPS ومكبّر صوت |
| كابل USB-C لنقل البيانات | كابل بيانات، **وليس** كابل شحن فقط |
| بطاقة microSD | أي سعة، مُهيّأة بنظام FAT32 |
| [VSCode](https://code.visualstudio.com) مع إضافة [PlatformIO](https://platformio.org) | للبناء والتنزيل على الجهاز |

---

## الخطوة الأولى — البناء والتنزيل (Flash)

```bash
git clone https://github.com/abdallahnatsheh/AL-ANQA-FIRMWARE
```

افتح المجلد المُستنسَخ داخل VSCode، وسيتعرّف PlatformIO على المشروع تلقائيًّا.

**اختر البيئة المناسبة لجهازك** (من شريط الحالة السفلي في VSCode):

| البيئة | متى تستخدمها |
|-------------|---------|
| `env:T-Deck` | جهاز T-Deck القياسي (بلا GPS وبلا مكبّر صوت) |
| `env:T-Deck-Plus` | جهاز T-Deck Plus (مع GPS ومكبّر صوت I2S) |

اضغط على زرّ **Upload** (سهم الرفع في الشريط السفلي) بعد توصيل الجهاز عبر منفذ USB.

**إذا فشلت عملية الرفع:**
اضغط مطوّلًا على **زرّ كرة التتبّع (Trackball)** أثناء توصيل كابل USB؛ فهذا يُجبر معالج ESP32-S3 على الدخول في وضع التنزيل (Download Mode). ثم أعد المحاولة. يمكنك ترك الزرّ بمجرّد أن تبدأ عملية الرفع.

## الخطوة الثانية — الإقلاع الأول

عند تشغيل الجهاز لأوّل مرّة ستظهر لك:
1. شاشة بدء العنقاء (Splash Screen)
2. شريط الحالة في الأعلى (أيقونات البطارية وBluetooth وWiFi وGPS)
3. مِحثّ الأوامر: `CMD>`

بذلك يكون الجهاز جاهزًا، ولا يلزمك شيء آخر قبل البدء بكتابة الأوامر.

**دلالات أيقونات شريط الحالة عند الإقلاع:**

| الأيقونة | ما تراه | الدلالة |
|------|-------------|---------|
| البطارية | أخضر / أصفر / أحمر | مستوى الشحن |
| `ᛒ` | رمادي | Bluetooth متوقّف (وهذا طبيعي عند الإقلاع) |
| القمر الصناعي | رمادي | GPS متوقّف — شغّله بالأمر `gps on` (لجهاز Plus) |
| الدرع | رمادي | نظام wguard غير قيد التشغيل |

## الخطوة الثالثة — إعداد بطاقة SD

بطاقة SD **اختيارية لكنها مُستحسَنة**؛ فبدونها لا تُحفَظ بيانات اعتماد WiFi ولا سجلّات المسح بين عمليات إعادة التشغيل.

**متطلّبات التهيئة:** نظام FAT32، وأي سعة.

أدخِل البطاقة ثم شغّل:

```
CMD> sdf init
```

يقوم هذا الأمر بتهيئة البطاقة (إن لم تكن بنظام FAT32 مسبقًا) وإنشاء بنية المجلّدات القياسية في خطوة واحدة:

```
/apps/          ← مجلّد لكل أمر (سجلّات، التقاطات، قوائم كلمات… إلخ)
/apps/badusb/scripts/  ← ملفات DuckyScript
/config/        ← الإعدادات العامة للجهاز (pwrsave، lockscreen، notif… إلخ)
```

للتأكّد من نجاح العملية:

```
CMD> sdinfo      # يعرض نوع البطاقة وسعتها
CMD> sdls /      # يسرد محتويات المجلّد الجذر
```

## الخطوة الرابعة — ضبط المنطقة الزمنية

تعتمد ساعة شريط الحالة وجميع الطوابع الزمنية في سجلّات الجلسات على المنطقة الزمنية المضبوطة. اضبطها مرّة واحدة وستبقى محفوظة بعد إعادة التشغيل:

```
CMD> tz +3               # UTC+3 (الرياض، موسكو… إلخ)
CMD> tz -5               # UTC-5 (شرق الولايات المتحدة، بلا توقيت صيفي)
CMD> tz +1               # CET (وسط أوروبا، بلا توقيت صيفي)
CMD> tz status           # لعرض الإعداد الحالي
```

كما تُقبَل صِيَغ POSIX الكاملة مع قواعد التوقيت الصيفي — راجع صفحة [المنطقة الزمنية]({{ site.baseurl }}/tz) لمزيد من التفاصيل.

## الخطوة الخامسة — إتقان واجهة الأوامر

### المِحثّ (Prompt)

```
CMD> _
```

اكتب الأمر ثم اضغط **Enter** أو **انقر بكرة التتبّع**. لا تُميّز الأوامر بين الأحرف الكبيرة والصغيرة، ولكلّ أمر اختصار قصير — فمثلًا `sw` هو `scanwifi`، و`nd` هو `netdiscover`، وهكذا.

### التنقّل بكرة التتبّع

| حركة كرة التتبّع | وظيفتها |
|-----------------|-------------|
| التمرير **يمينًا / يسارًا** | تحريك المؤشّر داخل الأمر المكتوب — للتعديل دون إعادة الكتابة |
| التمرير **للأعلى** | استرجاع الأمر السابق من السجلّ (حتى 16 أمرًا) |
| التمرير **للأسفل** | الانتقال إلى الأمر التالي، أو استعادة المسودّة التي كنت تكتبها |
| **النقر** | تنفيذ الأمر (يماثل مفتاح Enter) |
| **النقر المزدوج** | إطفاء الشاشة أو إيقاظها |
| **الضغط المطوّل 3 ثوانٍ** | قفل الشاشة (من أي شاشة أو تطبيق) |

### الإكمال التلقائي

اضغط مفتاح **`'`** (علامة الاقتباس المفردة — وهي مفتاح **Sym + K** على لوحة T-Deck) في أي لحظة أثناء الكتابة:

- **تطابق جزئي** — يُكمل أطول بادئة مشتركة
- **تطابق وحيد** — يُكمل الكلمة ويُضيف مسافة
- **تطابقات متعدّدة** — يعرض حتى 8 خيارات أسفل المِحثّ

ويعمل مع أسماء الأوامر ومسارات الملفات (في `sdls` و`cd` و`cat` و`rm`).

### سجلّ الأوامر

تُحفَظ آخر 16 أمرًا في ذاكرة حلقية (Ring Buffer). استخدم كرة التتبّع **للأعلى/للأسفل** للتنقّل بينها، مع الحفاظ على السطر الذي تكتبه حاليًّا؛ فالضغط **للأسفل** بعد أوّل إدخال يُعيد إليك مسودّتك.

## الخطوة السادسة — أوّل الأوامر

شغّل هذه الأوامر بالترتيب للتأكّد من أن كل شيء يعمل:

```
CMD> info         # معلومات الجهاز: الشريحة، وعناوين MAC، والبطارية، وحالة SD
CMD> help         # تصفّح جميع الأوامر مصنّفة حسب الفئة
CMD> sw           # مسح شبكات WiFi — للتأكّد من عمل الراديو
CMD> sbl          # مسح أجهزة BLE — للتأكّد من عمل Bluetooth
CMD> sdls /       # سرد جذر بطاقة SD — للتأكّد من إمكانية الوصول إليها
```

إذا أعاد الأمر `sw` شبكاتٍ وأعاد `sbl` أجهزةً، فجهازك يعمل بكامل طاقته.

---

## الخطوة السابعة — الاتصال بشبكة WiFi

تتطلّب معظم أدوات الشبكة اتصالًا فعّالًا بشبكة WiFi:

```
CMD> sw           # المسح — لاحظ رقم فهرس شبكتك
CMD> cw 2         # الاتصال بالشبكة ذات الفهرس 2
```

إذا لم تكن كلمة المرور محفوظة بعد، فسيُطلَب منك إدخالها، وتُحفَظ تلقائيًّا في بطاقة SD وفي ذاكرة NVS للاستخدام لاحقًا.

للتحقّق من الاتصال:

```
CMD> info         # تعرض الصفحة الثانية عنوان IP وقوّة الإشارة RSSI
CMD> pg 8.8.8.8   # اختبار Ping لخادم Google DNS — للتأكّد من الوصول إلى الإنترنت
```
