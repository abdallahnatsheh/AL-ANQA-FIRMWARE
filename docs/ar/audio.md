# الصوت والإشعارات

يستخدم العنقاء I2S (لا `tone()`) لكل الصوت على T-Deck Plus. ويوجد تحكّمان مستقلّان في الصوت: العام (`vol`) وصوت الإشعارات (`nf vol`).

---

## `volume` / `vol` — الصوت العام

```
CMD> vol          # عرض المستوى الحالي
CMD> vol 80       # الضبط على 80%
CMD> vol up       # +10%
CMD> vol down     # -10%
CMD> vol off      # كتم (0%)
```

محجوز لميزات مستقبلية (مشغّل MP3، مسجّل صوت). و**لا** يؤثّر في أصوات الإشعارات.

---

## `notif` / `nf` — مدير الإشعارات

### التفعيل / التعطيل

```
CMD> nf                  # شاشة الحالة
CMD> nf on               # تفعيل كل المستويات
CMD> nf off              # تعطيل كل المستويات
CMD> nf alert on         # تفعيل مستوى واحد
CMD> nf warning off      # تعطيل مستوى واحد
```

### الصوت

```
CMD> nf vol              # عرض صوت الإشعارات الحالي
CMD> nf vol 70           # الضبط على 70% (0-100)
```

صوت الإشعارات مستقلّ عن `vol`. فيمكن أن تكون الإشعارات عالية والموسيقى منخفضة، أو العكس.

### أصوات الاختبار

```
CMD> nf test            # مُنتقٍ تفاعلي — اضغط 1-5 للتشغيل، [a] الكلّ، [q] خروج
CMD> nf test alert      # تشغيل مستوى مباشرةً
```

يُشغّل `nf test` الصوت قسريًّا حتى لو كان المستوى مُطفأً، فهو أسرع طريقة لتجربة ملفّات WAV المخصّصة.

### مستويات الإشعارات

| المستوى | الإطلاق | النغمة الافتراضية |
|-------|---------|--------------|
| `alert` | عاصفة إلغاء مصادقة، توأم شرير، PMKID، WPA2 مكسورة، حصاد مصافحة | 3 × 1000 Hz |
| `warning` | إغراق مصادقة، عاصفة فحص، إغراق منارات | 2 × 700 Hz |
| `success` | التقاط مصافحة WPA، إيجاد SSID مخفي | 500→650→800 Hz تصاعدي |
| `info` | نغمة عامّة لمرّة | 500 Hz، 200 مِلّي ثانية |
| `ping` | وصول طلب رفيق BLE | 600 Hz، 100 مِلّي ثانية |

### WAV مخصّص لكل مستوى

المشغّل **WAV PCM خام** (لا MP3). حوّل أي صوت إلى **16-bit PCM، 22050 Hz، مونو**:

```
ffmpeg -i input.mp3 -ar 22050 -ac 1 -acodec pcm_s16le alert.wav
```

ضع ملفّات `.wav` في `/config/notification/` على بطاقة SD، ثم وجّه مستوى إلى الملفّ:

```
CMD> nf alert file alert.wav          # يُحَلّ إلى /config/notification/alert.wav
CMD> nf success file /sounds/ok.wav   # مسار مطلق
CMD> nf alert file                    # مسح — عودة للنغمة المدمجة
```

عند الإشعار، يتحقّق العنقاء إن كان WAV مضبوطًا لذلك المستوى. فإن وُجِدت SD والملفّ، شغّل WAV. وإلّا عاد للنغمة المدمجة I2S.

### ملفّ الإعداد — `/config/notif.conf`

يُنشَأ تلقائيًّا بـ `sdf init`. بصيغة مفتاح=قيمة:

```
notif_volume=70
alert=on
warning=on
success=on
info=on
ping=on
alert_file=alert.wav
```

الأسماء المجرّدة تُحَلّ تحت `/config/notification/`. والتغييرات بأوامر `nf` تُحفَظ تلقائيًّا.

### كل الملفّات

يجب أن تكون كل الملفّات **WAV 16-bit PCM، 22050 Hz، مونو**. أبقِها قصيرة (< ثانية) حتى لا تُبطئ الإشعارات الواجهة.

---

## `test spk` — اختبار المكبّر

اختبار عتاد تفاعلي. مفيد للتحقّق من مكبّر I2S وإعداد إشعاراتك. (كان `spktext` / `st` — والآن أمر فرعي لـ `test`؛ انظر [التشخيص]({{ site.baseurl }}/diagnostics).)

```
CMD> test spk
```

المفاتيح `1`–`6` و`s` تعزف نغمات I2S خام بأقصى شدّة — تتجاوز `nf vol` ومفيدة للتحقّق من عمل عتاد المكبّر. أمّا `a`/`w`/`c`/`i`/`p` فتمرّ عبر `NotificationManager` وتشغّل WAV المضبوط بصوت `nf vol`. وللتشغيل القسري بصرف النظر عن التبديل، استخدم `nf test`.

> **ملاحظة:** كل الصوت على T-Deck Plus يستخدم `i2s_driver_install()`. ودالّة `tone()` لا تعمل على هذا العتاد.
