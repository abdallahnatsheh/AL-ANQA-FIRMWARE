# الشاشة الرئيسية

<span class="label label-yellow">EXP</span>

## `home` / `hm` — تنكّر بشاشة رئيسية بأسلوب الهاتف

**مُطلِق تطبيقات** بأسلوب هاتف حديث يُستخدَم تنكّرًا متخفّيًا — بديلٌ لغطاء الملاحظات وحده. وبنظرة سريعة يبدو شاشةَ هاتف عادية؛ ولا يفتح شيئًا حقيقيًّا إلّا بلاطة **الملاحظات**.

```
CMD> home        # أو: hm
```

---

## التخطيط

- **شريط الحالة** — ساعة حقيقية (`HH:MM`)، ومشغّل مزيّف ("CRIMSON MOBILE")، وأعمدة إشارة، ومستوى **البطارية الحقيقي** (أخضر عند الشحن، أحمر عند ≤15%).
- **واجهة الساعة/الطقس** — وقت وتاريخ حيّان كبيران (عبر `ClockManager`) و**الطقس** الحالي (عبر [`weather` / `wx`]({{ site.baseurl }}/weather) — أيقونة شمس/غيوم/مطر/ثلج/رعد + درجة الحرارة + الحالة). يعرض `--` باهتًا حتى يُضبَط الطقس.
- **شبكة تطبيقات 4×2** — هاتف · رسائل · بريد · متصفّح · موسيقى · **ملاحظات** · تقويم · إعدادات، مع شارات غير مقروء على بعض البلاطات.

---

## استخدامه

| الإدخال | الإجراء |
|-------|--------|
| نقر بلاطة | **الملاحظات** تفتح تطبيق الملاحظات الحقيقي (انظر [الوضع المتخفّي]({{ site.baseurl }}/undercover))؛ وكل بلاطة أخرى تعرض رسالة "No service" ولا تفتح شيئًا |
| كرة التتبّع أعلى/أسفل/يمين/يسار | تحريك حلقة التحديد بين البلاطات |
| نقر كرة التتبّع | تشغيل البلاطة المحدَّدة |
| زرّ الرجوع **‹** في قائمة الملاحظات | انقره → يعيدك **هنا** للرئيسية. يظهر فقط حين فُتِحت الملاحظات من المُطلِق. |
| `q` **داخل قائمة الملاحظات** | مثل زرّ الرجوع — يعود للرئيسية. يعمل حتى مع عبارة مرور مضبوطة. |
| كتابة عبارة المرور | خروج صامت للأوامر (حين تُضبَط عبارة متخفّية) |
| `q` **في الشاشة الرئيسية** | خروج للأوامر — **فقط** حين لا عبارة مرور مضبوطة |

يرث المُطلِق **كل** سباكة التخفّي: كتم شريط الحالة عبر `displayManager.setBlocked`، وإعادة الرسم عند الإعتام→الاستيقاظ، وقوف شاشة القفل، والإيقاظ باللمس المزدوج، وخروج عبارة المرور عبر الذاكرة الحلقية.

---

## بيانات حيّة

- **الساعة** و**البطارية** حقيقيتان دائمًا (بلا إعداد).
- **الطقس** يُجلَب **عند الدخول** إن كان WiFi متّصلًا والقراءة المخزّنة قديمة. اضبطه مرّة بـ [`weather` / `wx`]({{ site.baseurl }}/weather). ولا يمكن معرفة الطقس دون اتصال — فهو بيانات خادم حيّة.

---

## ملاحظات

- هذا المُطلِق المستقلّ لضبط المظهر. ولم يُعرَض **بعد** كخيار غطاء لـ `undercover` (ملاحظات مقابل رئيسية) — وهذا مخطَّط.
- تُرسَم أيقونات التطبيقات كأشكال متّجهة (بلا خطّ أيقونات)، فتظهر على كلا اللوحين بلا أصول إضافية.

انظر أيضًا: [الوضع المتخفّي]({{ site.baseurl }}/undercover)، [الطقس]({{ site.baseurl }}/weather).
