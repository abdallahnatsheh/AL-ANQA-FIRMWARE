# مراقب إعلانات BLE — `bmon` / `bm`

مترصّد سلبي لإعلانات BLE. يُنصِت للمنارات التي يبثّها كل جهاز Bluetooth منخفض الطاقة قريب ويفكّ الصِّيَغ الشائعة — دون الاتصال بأي شيء.

---

## ما يفكّه

| الصيغة | يُعرَض |
|--------|-------|
| **iBeacon** (Apple، المصنّع `0x004C`) | UUID · Major · Minor · TxPower |
| **Eddystone-UID / URL / TLM** (خدمة `0xFEAA`) | Namespace/instance · URL · عدّاد الإعلان + وقت التشغيل |
| **اسم الجهاز** | الاسم المُعلَن نصّيًّا |
| **مصنّع غير معروف** | معرّف الشركة + أوّل بايتات الحمولة |

يعرض كل جهاز أيضًا **نوع عنوانه** — `pub` (MAC عامّ) أو `rnd` (MAC عشوائي/متبدّل) — و RSSI حيًّا وعدّاد مشاهدات.

---

## الاستخدام

```
CMD> bmon           # بدء الترصّد — تظهر الأجهزة الأحدث أوّلًا
```

| المفتاح / التحكّم | الإجراء |
|---------------|--------|
| كرة التتبّع **للأعلى/للأسفل** | تحديد صفّ — تعرض لوحة التفاصيل بياناته الكاملة |
| `a` / `l` | الصفحة السابقة / التالية (7 صفوف للصفحة) |
| `s` | تشغيل/إيقاف التسجيل إلى SD |
| `q` | الخروج |

تعرض اللوحة السفلية الحمولة **الكاملة** المفكوكة للجهاز المحدَّد (UUID كامل لـ iBeacon، namespace كامل لـ Eddystone، وقت تشغيل TLM، هيكس المصنّع الكامل).

---

## التسجيل

اضغط `s` للتسجيل إلى `/apps/bmon/NNN.csv` (تسلسلي، لا يُستبدَل). وتُزال التكرارات لكل MAC كل 60 ثانية.

```
timestamp,first_seen,mac,addr_type,type,rssi,sightings,info,extended
```

- `info` — السلسلة القصيرة المعروضة
- `extended` — البيانات الكاملة المفكوكة

الطوابع الزمنية من `ClockManager` (GPS/NTP)؛ فإن لم تُضبَط الساعة بعد، تعود إلى `@<مِلّي ثانية منذ الإقلاع>`.

---

## أمثلة

**إيجاد UUID/Major/Minor لـ iBeacon** — شغّل `bmon`، وحدّد الصفّ الموسوم `iBeacon`، واقرأ لوحة التفاصيل.

**تدقيق ما يسرّب MAC ثابتًا** — الصفوف الموسومة `pub` تبثّ عنوانًا ثابتًا (قابلًا للتتبّع)؛ و`rnd` تبدّل عناوينها. سجّل بـ `s` وافتح CSV على حاسوب.
