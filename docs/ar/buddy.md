# رفيق Claude Desktop

**تحكّم في Claude Desktop من جهاز T-Deck — وافِق على طلبات الأذونات، وراقب إحصاءات الجلسة الحيّة، وربِّ حيوانًا أليفًا بأسلوب ASCII.**

---

## `buddy` / `bd` — ريموت Claude Desktop

```
CMD> buddy
CMD> bd
CMD> bd MyAl-Anqa    # اسم إعلان BLE مخصّص
```

يربط T-Deck بـ [claude-desktop-buddy](https://github.com/anthropics/claude-desktop-buddy) عبر خدمة Nordic UART (NUS) لـ BLE. وبمجرّد الربط، يبثّ Claude Desktop بيانات الجلسة الحيّة وطلبات الأذونات المعلّقة إلى الجهاز. فتوافق أو ترفض من لوحة المفاتيح — بلا هاتف، وبلا تفاعل مع سطح المكتب.

**يتطلّب:** Claude Desktop مع تفعيل وضع المطوّر ← Hardware Buddy.

---

## تخطيط الشاشة

تنقسم الشاشة إلى لوحتين:

```
┌─────────────────────┬────────────────┐
│  اللوحة اليسرى 160px │  اللوحة اليمنى │
│  إحصاءات + تحكّم     │  رسوم ASCII    │
└─────────────────────┴────────────────┘
```

**اللوحة اليسرى — من الأعلى للأسفل:**

| القسم | المحتوى |
|---------|---------|
| الرأس | اسم الفصيلة (يسار) · حالة BLE (يمين) |
| mood | 4 قلوب صغيرة — سرعة موافقتك على الطلبات |
| fed | 10 دوائر — تقدّم الرموز نحو المستوى التالي |
| energy | 5 أعمدة — تنضب مع الوقت أثناء عمل `bd` |
| شارة المستوى | `Lv N` بلون جسم الفصيلة |
| approved | عدد طلبات الأذونات الموافَق عليها مدى الحياة |
| denied | عدد الطلبات المرفوضة مدى الحياة |
| napped | إجمالي الوقت داخل جلسات `bd` |
| tokens | إجمالي رموز الخرج التراكمية مدى الحياة |
| today | الرموز المستخدَمة في جلسة Claude Desktop الحالية |
| HUD | طلب موافقة **أو** رسالة حالة خمول |

**اللوحة اليمنى:** واحدة من 19 فصيلة حيوان ASCII، تتحرّك بـ 5 إطارات/ثانية. وتتغيّر الفصيلة حسب ما يفعله Claude (نائم، مشغول، انتباه، احتفال… إلخ).

## المفاتيح

| المفتاح | الإجراء |
|-----|--------|
| `y` | الموافقة على طلب الإذن المعلّق |
| `n` | رفض طلب الإذن المعلّق |
| `space` | التنقّل للفصيلة التالية (معطّل أثناء فتح النافذة) |
| `q` | الخروج والعودة لواجهة الأوامر |

## مسار الموافقة

عندما يحتاج Claude Desktop إذنًا (كتابة ملفّ، أمر bash… إلخ) تتحوّل الشاشة إلى نافذة طرفية بملء الشاشة:

```
╔══════════════════════════════════════════╗
║  PERMISSION REQUEST                      ║
╠══════════════════════════════════════════╣
║  BashTool                                ║
║  ping -c 4 192.168.1.1 && traceroute     ║
║  waiting 8s                              ║
║  [y] approve                   [n] deny  ║
╚══════════════════════════════════════════╝
```

يُعرَض اسم الأداة بحجم مضاعف إن كان 13 حرفًا أو أقلّ. ويُلَفّ الأمر/التلميح الكامل على أسطر بحسب الحاجة — بلا اقتطاع. ويتحوّل المؤقّت للأحمر بعد 10 ثوانٍ. وضغط `y` أو `n` يرسل القرار إلى Claude Desktop فورًا عبر BLE وتُغلق النافذة، فتعود رؤية الحيوان الأليف.

> **ملاحظة:** نصّ التلميح المعروض هو ما يرسله جسر Claude Desktop في حقل `hint` بصيغة JSON. وقد يقتطع الجسر الأوامر الطويلة جدًّا على جانب سطح المكتب قبل الإرسال — وهذا خارج سيطرة T-Deck.

## شرح الإحصاءات

### mood — 4 قلوب

يتتبّع سرعة استجابتك لطلبات الأذونات. فكل ضغطة `y` تسجّل عدد الثواني منذ ظهور الطلب. ووسيط آخر 8 استجابات يحدّد المستوى الأساسي:

| زمن الاستجابة | القلوب |
|---------------|--------|
| أقلّ من 15 ثانية | 4 (أقصى) |
| أقلّ من 30 ثانية | 3 |
| أقلّ من 60 ثانية | 2 |
| أقلّ من دقيقتين | 1 |
| أكثر من دقيقتين | 0 |

إن تجاوزت نسبة رفضك 33%، فقد المزاج مستوى. وإن رفضت أكثر ممّا وافقت، فقد مستويين.

### fed — 10 دوائر

مدفوع بالرموز. يرسل Claude Desktop عدد رموز خرجه التراكمي كل نبضة. ويعرض شريط fed التقدّم نحو المستوى التالي — كل 5,000 رمز يملأ نقطة، و50,000 رمز = شريط كامل = **ارتقاء مستوى**. وعند الارتقاء يعزف الحيوان رسوم الاحتفال ويُصفَّر الشريط.

### energy — 5 أعمدة

يبدأ 5/5 (كامل) كل مرّة تفتح `bd`. وينضب عمود كل ساعتين أثناء عمل الأمر. وإغلاق `bd` وإعادة فتحه يستعيده كاملًا — فكل بدء جلسة يُحسَب "استيقاظًا".

### Lv N — المستوى

`رموز مدى الحياة ÷ 50,000`. يزداد دائمًا. فالمستوى 1 = 50 ألف رمز، والمستوى 2 = 100 ألف، وهكذا.

### approved / denied

عدّادات بسيطة مدى الحياة لكل `y` و`n`. وكلاهما يؤثّر في حساب المزاج.

### napped

إجمالي الوقت الفعلي داخل الأمر `bd` عبر كل الجلسات. يتراكم عند الخروج ويُحفَظ في NVS.

### tokens / today

**tokens** — رموز الخرج التراكمية مدى الحياة منذ أوّل تشغيل لـ `bd`. تحرّك المستوى و fed.

**today** — عدّاد حيّ من جلسة Claude Desktop الحالية. يُصفَّر عند إعادة تشغيل الجسر. لا يُحفَظ.

## الحفظ الدائم

تُخزَّن الإحصاءات في NVS (تبقى بعد انقطاع التيار) تحت مساحة `buddy`:

| الإحصاء | محفوظ |
|------|-----------|
| tokens (مدى الحياة) | نعم |
| level | نعم (مشتقّ) |
| approvals | نعم |
| denials | نعم |
| سجلّ المزاج | نعم |
| napped | نعم |
| energy | لا — يُصفَّر 5/5 كل فتح لـ `bd` |
| today tokens | لا — حيّ من الجسر |

تُحفَظ الإحصاءات فورًا عند الأحداث المهمّة (موافقة، رفض، ارتقاء) وعند الخروج. وتآكل NVS ضئيل — بلا حفظ مؤقّت.

## فصائل الحيوانات

19 فصيلة منقولة من مشروع [claude-desktop-buddy](https://github.com/anthropics/claude-desktop-buddy) الرسمي. لكلٍّ 7 حالات متحرّكة:

| الحالة | الإطلاق |
|-------|---------|
| sleep | غير متّصل بـ Claude Desktop |
| idle | متّصل، لا شيء نشط |
| busy | 3 جلسات فأكثر معًا |
| attention | طلب إذن ينتظر |
| celebrate | مهمّة أُنجِزت مؤخّرًا · ارتقاء |
| dizzy | (محجوز) |
| heart | وافق على طلب خلال 5 ثوانٍ |

اضغط `space` للتنقّل بين الـ 19 فصيلة. والفصيلة الأولى عشوائية كل تشغيل.

**قائمة الفصائل:** axolotl · blob · cactus · capybara · cat · chonk · dragon · duck · ghost · goose · mushroom · octopus · owl · penguin · rabbit · robot · snail · trex · turtle

## الإعداد

1. ثبّت [claude-desktop-buddy](https://github.com/anthropics/claude-desktop-buddy) على سطح مكتبك.
2. في Claude Desktop ← **Developer** ← **Hardware Buddy** ← فعّل.
3. على T-Deck، شغّل `bd` — يُعلن باسم `Claude-XXXX` (آخر بايتين من BT MAC).
4. يتّصل Claude Desktop تلقائيًّا عبر مسح BLE.

يُعلن T-Deck باستمرار. ويعيد Claude Desktop الاتصال تلقائيًّا بعد أي انقطاع.

## تفاصيل تقنية

| الخاصّية | القيمة |
|----------|-------|
| الناقل | BLE Nordic UART Service (NUS) |
| معرّف الخدمة | `6e400001-b5a3-f393-e0a9-e50e24dcca9e` |
| البروتوكول | JSON مفصول بأسطر |
| حزمة BLE | NimBLE 2.5.x |
| مساحة NVS | `buddy` |
| الأمان | NUS عادي (بلا ارتباط/مفتاح مرور) |

**شاشة القفل:** يمكن قفل الجهاز أثناء عمل `bd`. فتتوقّف رسوم الحيوان واللوحة اليسرى عن الرسم فورًا. وعند فتح القفل تُعاد رسمهما تلقائيًّا — بلا ضغط مفتاح.

**سلوك معروف:** عند الإقلاع البارد (لم تُهيّأ BLE قطّ)، شغّل `sbl` مرّة قبل `bd` لإحماء متحكّم BLE — أو انتظر تأخير التهيئة 200 مِلّي ثانية المضاف إلى `bd` الذي يعالج ذلك تلقائيًّا.
