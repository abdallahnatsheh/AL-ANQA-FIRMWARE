# المسح والاتصال

---

## `scanwifi` / `sw` — مدير WiFi

```
CMD> sw          # مدير WiFi تفاعلي (يمسح عند الدخول)
CMD> sw on       # تشغيل الراديو (وضع STA)
CMD> sw off      # إيقاف الراديو (فصل الاتصال، خمول)
```

يفتح الأمر `sw` **مدير WiFi** تفاعليًّا: قائمة قابلة للتمرير بالشبكات المجاورة على تردّد 2.4 GHz (الفهرس، الاسم SSID، قوّة الإشارة RSSI، الحماية، WPS) مع **سطر حالة** حيّ في الأعلى يعرض الاتصال الحالي (SSID · IP · RSSI) أو `Not connected` / `Radio OFF`.

| المفتاح | الإجراء |
|-----|--------|
| كرة التتبّع ↑ / ↓ | تحريك التحديد |
| نقر كرة التتبّع / `Enter` | الاتصال بالشبكة المحدَّدة |
| `d` | قطع الاتصال |
| `f` | نسيان الشبكة المحدَّدة (يزيلها من NVS **و** من `/wpa_supplicant.conf`) |
| `o` | تبديل حالة الراديو (تشغيل / إيقاف) |
| `l` / `a` | صفحة للأسفل / للأعلى |
| `u` | إعادة المسح |
| `q` | الخروج |

يعيد الاتصال استخدام المسار نفسه الذي يستخدمه `cw` (يطلب كلمة المرور إن كانت مجهولة، ثم يحفظها في NVS و`/wpa_supplicant.conf`). و**"إيقاف الراديو" يترك WiFi في حالة STA خاملة** — فهو لا يستخدم `WIFI_OFF` مطلقًا، ليبقى آمنًا من حيث GDMA وجاهزًا لإعادة المسح.

تُخزَّن نتيجة المسح مؤقتًا — استخدم `show wifi` لعرضها مجدّدًا دون إعادة مسح. ويبقى فهرس المسح (`#`) هو نفسه الذي تستخدمه أوامر `cw` / `da` / `et` / `hs` / `ws`.

### عمود الحماية

تُوسَم كل شبكة بحسب نمط المصادقة الذي تُعلن عنه نقطة الوصول:

| الوسم | المعنى | اللون |
|-----|---------|------|
| `OPEN` | بلا تشفير | أرجواني |
| `WEP` | تشفير WEP القديم | أحمر |
| `WPA` / `WPA2` | حماية WPA / WPA2-PSK | رمادي |
| `WPA3` | WPA3 خالص (SAE فقط) — غير قابل للخفض (Downgrade) | أخضر |
| `WPA3/TD` | **الوضع الانتقالي** — تقبل WPA2 **و** WPA3 معًا | **أصفر** |

يشير الوسم `WPA3/TD` (الأصفر) إلى نقطة وصول تدعم WPA3 لكنها ما زالت تقبل WPA2، ممّا يجعلها هدفًا مرشّحًا لهجوم **خفض الوضع الانتقالي لـ WPA3** — وهي فئة الهدف لأمر [`wpa3down` / `w3d`]({{ site.baseurl }}/wpa3down). أمّا نقطة الوصول التي تدعم WPA3 خالصًا (SAE فقط) فتظهر بوسم `WPA3` (أخضر). ويأتي هذا التصنيف مباشرةً من حقل `authmode` في سجلّ مسح ESP32 (بلا فحص إضافي وبلا إرسال).

## `connectwifi` / `cw` — الاتصال بشبكة

```
CMD> cw <index>    # الاتصال حسب فهرس المسح من آخر sw
CMD> cw <ssid>     # الاتصال حسب اسم الشبكة SSID
```

يتّصل بشبكة عبر الفهرس أو اسم SSID. تُستخرَج كلمة المرور تلقائيًّا من NVS أوّلًا، ثم من `/wpa_supplicant.conf` في بطاقة SD. ولا يُطلَب منك إدخالها إلّا إن لم تُوجَد.

وعند نجاح الاتصال تُحفَظ الشبكة في `/wpa_supplicant.conf`.

> لإدارة بيانات الاعتماد والمزامنة مع Linux، راجع دليل [بيانات اعتماد WiFi]({{ site.baseurl }}/wifi-credentials).

## `wp clear` — مسح بيانات الاعتماد المحفوظة

```
CMD> wp clear
```

يمسح جميع كلمات مرور WiFi المحفوظة من ذاكرة NVS. وعند الاتصال التالي بشبكة معروفة سيُطلَب إدخال كلمة المرور من جديد. (كان سابقًا الأمر المستقلّ `clearwifi` / `clrw`، وأُدمِج الآن في `wifipass`؛ راجع دليل [بيانات اعتماد WiFi]({{ site.baseurl }}/wifi-credentials).)
