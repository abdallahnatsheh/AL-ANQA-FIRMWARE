# مرجع لوحة المفاتيح

يمتلك جهاز T-Deck لوحة مفاتيح **QWERTY فعلية** تتواصل مع معالج ESP32-S3 عبر ناقل I2C، وترسل بايت ASCII واحدًا لكل ضغطة مفتاح؛ إذ يتكفّل برنامج لوحة المفاتيح بمعالجة مفاتيح التعديل (Modifiers) وتحديد الحرف النهائي قبل أن يصل إلى العنقاء.

---

## التخطيط الفعلي

```
┌───┬───┬───┬───┬───┬───┬───┬───┬───┬───┐
│ Q │ W │ E │ R │ T │ Y │ U │ I │ O │ P │
├───┼───┼───┼───┼───┼───┼───┼───┼───┼───┤
│ A │ S │ D │ F │ G │ H │ J │ K │ L │ ⏎ │
├───┴┬──┴┬──┴┬──┴┬──┴┬──┴┬──┴┬──┴┬──┴───┤
│SYM │ Z │ X │ C │ V │ B │ N │ M │  ⌫  │
├────┴──┬┴───┴───┴───┴───┴───┴┬──┴──────┤
│  ALT  │        SPACE        │  (mic)  │
└───────┴─────────────────────┴─────────┘
```

> يحتوي **T-Deck Plus** على زرّ ميكروفون في الصفّ السفلي، أمّا في T-Deck القياسي فقد يكون غائبًا أو مستبدلًا بمفتاح فارغ.

## مفاتيح التعديل (Modifiers)

### SYM — الرموز الخاصة

اضغط مطوّلًا على **SYM** ثم اضغط حرفًا لكتابة الرمز الظاهر في الجزء السفلي من المفتاح. والحروف الثانوية مطبوعة على أغطية المفاتيح نفسها — فراجع جهازك لمعرفة التخطيط الدقيق.

**مؤكَّد من البرنامج:**

| التركيبة | الحرف | الاستخدام |
|-------|-----------|---------|
| SYM + K | `'` (علامة اقتباس مفردة) | **مُشغّل الإكمال التلقائي** في واجهة الأوامر |
| SYM + 0 | `=` (علامة يساوي) | إعادة تعيين من العنقاء — لوحة مفاتيح LilyGo الأصلية لا تحوي مفتاح `=` على الإطلاق، فيتعذّر إدخال أي كلمة مرور WiFi أو وسيط CLI يحتوي على `=` ([المشكلة #3](https://github.com/abdallahnatsheh/AL-ANQA-FIRMWARE/issues/3)). يُرسل معالج لوحة المفاتيح البايت `0xE0` عند SYM+0 (وهي تركيبة غير مُستخدمة أصلًا)، ويقوم `boardReadKey()` بترجمته إلى `'='` قبل أن تراه أي أمر — فيعمل في كل مكان: موجّه CLI، محرّر `edit`، `wp add`، مُوجّه HID عبر `ux`، `bk`، محرّر الملاحظات، إدخال PIN لشاشة القفل، إلخ. هذا للـ T-Deck / T-Deck-Plus فقط — أما T-Pager فيمتلك مفتاح `=` فعليًا على SYM+5. |

أمّا بقيّة رموز Sym فتظهر مباشرةً على المفاتيح — انظر إلى الركن الأيمن السفلي من كل غطاء مفتاح.

> **لاكتشاف تركيبات أخرى غير مُعيَّنة:** شغّل `test keydump` (متوفر على T-Deck / T-Deck-Plus فقط) لرؤية البايت الخام الذي يرسله معالج لوحة المفاتيح لأي مفتاح أو تركيبة. مفيد إذا وجدت حرفًا مفقودًا آخر تريد إعادة تعيينه.

### ALT — الأرقام وعلامات الترقيم

يتيح مفتاح **ALT** الوصول إلى الأرقام وعلامات الترقيم الإضافية. وفي معظم لوحات T-Deck تعمل مفاتيح الصفّ العلوي (من Q إلى P) أرقامًا من 1 إلى 0 عند دمجها مع ALT.

راجع لوحة مفاتيحك الفعلية؛ فالحروف الثانوية مطبوعة على أوجه المفاتيح.

---

## المفاتيح الخاصة

| المفتاح | يُرسل | أثره في واجهة الأوامر |
|-----|-------|--------------|
| `⏎` Enter | تنفيذ | يُشغّل الأمر الحالي |
| `⌫` Backspace | `\b` | يحذف الحرف الواقع يسار المؤشّر |
| **الضغط المطوّل** على Backspace لمدّة 1.5 ثانية | `\b` متكرّر | حذف تلقائي بمعدّل نحو 16 حرفًا في الثانية |
| SYM + K | `'` | يُشغّل الإكمال التلقائي |
| Space | ` ` | يُدرج مسافة |

## كرة التتبّع (Trackball)

تعمل كرة التتبّع فأرةً (في وضع لوحة مفاتيح USB/BLE) وأداةَ تنقّل في واجهة الأوامر في آنٍ واحد.

### عند مِحثّ الأوامر

| الإجراء | الأثر |
|--------|--------|
| التمرير **يسارًا** | تحريك المؤشّر موضعًا واحدًا إلى اليسار داخل الأمر المكتوب |
| التمرير **يمينًا** | تحريك المؤشّر موضعًا واحدًا إلى اليمين |
| التمرير **للأعلى** | استدعاء الأمر السابق من السجلّ |
| التمرير **للأسفل** | استدعاء الأمر التالي من السجلّ (أو استعادة المسودّة) |
| **النقر** | تنفيذ الأمر (يماثل Enter) |
| **النقر المزدوج** | إطفاء الشاشة أو إيقاظها |
| **الضغط المطوّل 3 ثوانٍ** | قفل الشاشة فورًا (من أي شاشة) |

### في العروض المُقسَّمة إلى صفحات (نتائج المسح، المساعدة، صفحات الدليل)

| الإجراء | الأثر |
|--------|--------|
| التمرير **للأعلى** / `a` | الصفحة السابقة |
| التمرير **للأسفل** / `l` | الصفحة التالية |
| `q` | الخروج / الإغلاق |

### في عارض الملفات `cat`

| الإجراء | الأثر |
|--------|--------|
| التمرير **للأعلى** | التمرير إلى الأعلى |
| التمرير **للأسفل** | التمرير إلى الأسفل |
| `q` | الخروج |

## اختصارات واجهة الأوامر

### الإكمال التلقائي — `'` (SYM + K)

اضغط `'` في أي لحظة أثناء الكتابة لتشغيل الإكمال التلقائي:

| الحالة | ما يحدث |
|-----------|-------------|
| تطابق وحيد | تُكمَل الكلمة وتُضاف مسافة |
| تطابقات متعدّدة | تُعرَض حتى 8 خيارات أسفل المِحثّ |
| بادئة مشتركة | تُملأ البادئة ويتقدّم المؤشّر |
| لا تطابق | لا يحدث شيء |

ويعمل مع **أسماء الأوامر**، و**مسارات الملفات** (`sdls` و`cd` و`cat` و`rm`)، و**تلميحات الأوامر الفرعية** لأوامر مثل `pwrsave` و`notif` و`macchanger` و`wguard` و`ssh` — فكتابة الأمر ثم مسافة ثم `'` تعرض وسائطه الصالحة بالأصفر.

مثال:
```
CMD> sca'       → يُكمل إلى "scanwifi " أو يعرض: scanwifi, scanblue
CMD> cat /ap'   → يُكمل إلى "cat /apps/"
CMD> ssh '      → save list rm بالإضافة إلى أسماء المضيفين المحفوظة (nas, vps, ...)
CMD> ssh n'     → يُكمل إلى "ssh nas " (ملف مضيف محفوظ)
```

### سجلّ الأوامر

تُحفَظ آخر **16 أمرًا** في ذاكرة حلقية داخل RAM (ولا تبقى بعد إعادة التشغيل).

| الإجراء | الأثر |
|--------|--------|
| كرة التتبّع **للأعلى** | استدعاء الأمر السابق، مع حفظ النصّ الذي تكتبه حاليًّا تلقائيًّا |
| كرة التتبّع **للأسفل** | التقدّم في السجلّ؛ وتجاوز أحدث إدخال يُعيد إليك نصّك الأصلي |

ولا تُحفَظ الأوامر المتتالية المكرّرة — فتنفيذ الأمر نفسه مرّتين متتاليتين يُخزَّن مرّة واحدة فقط.

### تحرير المؤشّر

يمكنك التحرير في أي موضع من الأمر دون إعادة كتابته من جديد:

1. حرّك كرة التتبّع يمينًا/يسارًا لضبط موضع المؤشّر
2. اكتب لـ**إدراج** الحروف عند موضع المؤشّر
3. يحذف Backspace الحرف الواقع **يسار** المؤشّر

وهذا يماثل تمامًا محرّر الأسطر في أي طرفية قياسية.

## سلوك المفاتيح داخل التطبيقات

تستجيب معظم الأوامر التفاعلية (عمليات المسح، والهجمات، والعارضات) لما يلي:

| المفتاح | الأثر المعتاد |
|-----|---------------|
| `q` / `Q` | الخروج / إيقاف الأمر الحالي |
| `l` | الصفحة التالية |
| `a` | الصفحة السابقة |
| `u` | إعادة المسح / التحديث |
| `s` | الحفظ في بطاقة SD |
| `y` / `n` | تأكيد بنعم / لا |
| كرة التتبّع للأعلى/للأسفل | التمرير (في العارضات) أو التنقّل في السجلّ (عند المِحثّ) |

---

## نصائح للكتابة

- **الأحرف الكبيرة:** اضغط مطوّلًا على SYM أثناء كتابة الحروف، أو اضغط SYM ثم ALT — وراجع الطباعة الحريرية على لوحتك لمعرفة السلوك الدقيق
- **الأرقام:** استخدم ALT مع مفاتيح الصفّ العلوي (أو تحقّق ممّا إذا كانت لوحتك تحتوي على صفّ أرقام)
- **Tab:** تربط بعض اللوحات SYM + Space بمفتاح Tab — وإلّا فاستخدم مفتاح الإكمال التلقائي `'` للتنقّل بين المسارات
- **تصحيح خطأ مطبعي:** حرّك كرة التتبّع إلى موضع الخطأ واكتب فوقه — فوضع الإدراج فعّال دائمًا
- **الأوامر الطويلة:** استخدم الإكمال التلقائي (`'`) لتجنّب كتابة المسارات وأسماء الأوامر كاملةً
