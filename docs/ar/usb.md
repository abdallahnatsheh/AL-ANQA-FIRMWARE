# USB Gadget

يستطيع العنقاء تقديم T-Deck كأجهزة USB للحاسوب المتّصل. وكل الأوضاع مفعّلة عند الإقلاع — بلا إعادة تنزيل. ولكل أداة صفحتها (على اليسار) بكامل التفاصيل.

> وضعا MSC و KBD/BadUSB متعارضان وقت التشغيل، لكنهما يتقاسمان اتصال USB نفسه.
