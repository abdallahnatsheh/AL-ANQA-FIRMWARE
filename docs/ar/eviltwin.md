# التوأم الشرير (Evil Twin)

## `eviltwin` / `et`

يستنسخ نقطة وصول مجاورة ويشغّل بوّابة أَسر (Captive Portal) لالتقاط بيانات الاعتماد. شغّل `et` لفتح مُنتقي الشبكات.

```
CMD> et
```

### الاستراتيجية بحسب نوع الهدف

| مصادقة الهدف | استراتيجية MAC | الأثر |
|-------------|-------------|--------|
| شبكة مفتوحة | استنساخ عنوان MAC والقناة الحقيقيَّين لنقطة الوصول | تعيد الأجهزة الاتصال بسلاسة |
| WPA/WPA2 | عنوان MAC عشوائي مُدار محلّيًّا + إلغاء مصادقة نقطة الوصول الحقيقية | تلتقط البوّابة بيانات الاعتماد |

**إلغاء المصادقة التكيّفي** — تنطلق دفعات إلغاء المصادقة كل 8 ثوانٍ، وتتوقّف تلقائيًّا أثناء اتصال عميل بالبوّابة حتى يتمكّن من إرسال نموذج بيانات الاعتماد.

### صفحات البوّابة

يأتي البرنامج بقالبين مدمجين (تسجيل دخول Google، تحديث برنامج راوتر). ضع ملفات `.html` إضافية في `/apps/eviltwin/portal/` على بطاقة SD.

اضغط **`p`** لفتح مُنتقي البوّابات — يعرض **جميع** القوالب المدمجة وقوالب SD عبر صفحات (`n`/`p` للتنقّل، ومفتاح رقمي للاختيار). ويُبرَز القالب النشط حاليًّا، ويؤكّد إشعار أخضر على الشاشة كل تبديل. ويعيد التبديل تشغيل خدمة DNS للبوّابة حتى تستمرّ نافذة "تسجيل الدخول إلى الشبكة" بالظهور للعملاء الجدد.

**توافق البوّابات** — مُلتقِط بيانات الاعتماد لا يعتمد على مسار أو أسماء حقول محدّدة، لذا تعمل معه أي بوّابة أَسر HTML تقريبًا دون تعديل:

- يقبل إرسال النماذج إلى `/post` *أو* `/get`، عبر **GET أو POST** (ويلتقط المسارات الغريبة عبر معالِج احتياطي).
- يتعرّف على حقول اسم المستخدم المسمّاة `email` و`user` و`username` و`uname` و`login` و`account` و`phone` و`identifier` و`id` و`name`… وحقول كلمة المرور `password` و`pass` و`pwd` و`psw` و`passcode` و`pin`. أمّا الحقول غير المتعلّقة ببيانات الاعتماد (`remember` و`csrf` و`token`…) فتُتجاهَل.

> إن ظلّت بوّابة لا تعرض أي بيانات اعتماد، فتأكّد من أن نموذجها يرسل القيم المُدخَلة فعلًا (بعض الصفحات المزحيّة بلا نموذج حقيقي). ولا حاجة لتعديل HTML من أجل أسماء الحقول.

### تخزين بيانات الاعتماد

تُخزَّن بيانات الاعتماد الملتقَطة مؤقتًا **في الذاكرة أثناء الجلسة** (حتى 30) — وهي عمدًا *لا* تُكتَب إلى SD أثناء نشاط راديو نقطة الوصول / إلغاء المصادقة، لأن تزامن DMA لـ WiFi و SD قد يُتلف البطاقة (قاعدة GDMA في ESP32-S3). ويسجّل كل التقاط طابعًا زمنيًّا.

وتُفرَّغ إلى `/apps/eviltwin/creds.csv` (بالإلحاق فقط، مع الحفاظ على الطوابع الزمنية):

- تلقائيًّا عند الخروج (`q`)، في النافذة الآمنة بعد إيقاف الراديو،
- وعند الطلب بالمفتاح **`s`** (نقطة حفظ أثناء الجلسة — يوقف راديو المراقبة مؤقتًا حول عملية الكتابة).

### المفاتيح

| المفتاح | الإجراء |
|-----|--------|
| `p` | اختيار صفحة البوّابة (المدمجة + كل قوالب SD، مُقسَّمة لصفحات) |
| `c` | عرض بيانات الاعتماد الملتقَطة (تبقى البوّابة عاملة) |
| `s` | حفظ بيانات الاعتماد الملتقَطة إلى SD |
| `q` | إيقاف التوأم الشرير (يحفظ تلقائيًّا ما تبقّى) |
