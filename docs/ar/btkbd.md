# لوحة مفاتيح Bluetooth

## `btkbd` / `bk` — لوحة مفاتيح وفأرة BLE HID

يحوّل T-Deck إلى لوحة مفاتيح وفأرة Bluetooth HID. يقترن عبر Just Works (بلا PIN). ومشفّر بـ AES-128 بعد الاقتران. يرتبط بـ Windows — ويعيد الاتصال تلقائيًّا في المرّة التالية.

```
CMD> bk
```

**المرحلة 1 — الاقتران:** يُعلن العنقاء نفسه باسم `AL-ANQA-KBD`. اقترن من إعدادات Bluetooth في المضيف. اضغط كرة التتبّع مطوّلًا 1.5 ثانية للإلغاء.

**المرحلة 2 — نشط:** يُمرَّر كل مفتاح في T-Deck كضغطة HID. وتتحكّم كرة التتبّع بمؤشّر الفأرة.

### زرّ منتصف كرة التتبّع

| الإجراء | النتيجة |
|--------|--------|
| نقرة سريعة (< 300 مِلّي ثانية) | نقرة يسار |
| ضغط 300 مِلّي ثانية – 1.5 ثانية | نقرة يمين |
| ضغط ≥ 1.5 ثانية | الخروج |

**تكرار Backspace التلقائي:** اضغط Backspace مطوّلًا 1.5 ثانية ← تكرار بنحو 16 حرفًا/ثانية.

> يستخدم عنوان BLE منفصلًا عن `buddy` (اللاحقة `:CB` مقابل `:BD`) حتى يرتبط Windows بالجهازين مستقلَّين. فإن أظهر Windows أخطاء مصادقة، احذف الجهاز من إعدادات Bluetooth وأعد الاقتران.
