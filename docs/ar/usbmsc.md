# التخزين الكتلي USB

## `usbmsc` / `um`

يركّب بطاقة SD كقرص USB قابل للإزالة على الحاسوب المضيف. بلا حاجة لمُشغّلات على Windows أو macOS أو Linux.

```
CMD> um
```

تعرض شاشة T-Deck حجم البطاقة وتنتظر. استخدم بطاقة SD عاديًّا من الحاسوب — اقرأ واكتب واحذف الملفّات.

### للخروج

1. أخرِج القرص من الحاسوب (إزالة آمنة للعتاد)
2. اضغط `q` على لوحة T-Deck

### ملاحظات

- يُفصَل WiFi تلقائيًّا قبل بدء MSC (ناقل GDMA مشترك في ESP32-S3)
- تُبقى كل أطراف SPI CS مرتفعة أثناء MSC لمنع تلف الناقل
- تُعاد تهيئة بطاقة SD تلقائيًّا لاستخدام العنقاء عند الخروج (حتى 8 محاولات)
- أخرِج القرص من الحاسوب دائمًا قبل الضغط على `q` — لا تفصل الكابل أثناء الكتابة
