# معلومات الجهاز

## `info` / `inf`

```
CMD> info
```

عرض معلومات الجهاز في 4 صفحات.

| الصفحة | المحتوى |
|------|---------|
| 1 (SYS) | طراز الشريحة، الأنوية، حجم الفلاش، PSRAM، تردّد المعالج، الكومة، وقت التشغيل |
| 2 (RADIO) | MAC لـ WiFi، MAC لـ BT، عنوان IP، قوّة إشارة WiFi |
| 3 (HW) | نسبة البطارية، حالة بطاقة SD، أطراف LoRa، حالة GPS |
| 4 (ABOUT) | اسم المشروع + **رمز QR** قابل للمسح يربط بـ [مستودع GitHub](https://github.com/abdallahnatsheh/AL-ANQA-FIRMWARE) |

| المفتاح | الإجراء |
|-----|--------|
| `l` / `a` | الصفحة التالية / السابقة |
| `s` | إعادة عرض شاشة البداية (العنقاء) — اضغط أي مفتاح للعودة |
| `q` | الخروج |
