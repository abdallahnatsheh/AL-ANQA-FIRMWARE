# أوامر SD

```
CMD> sdinfo                  # نوع بطاقة SD وحجمها واستخدامها
CMD> sdls [path]             # سرد مجلّد (الافتراضي: الحالي)
CMD> cd <path|..>            # تغيير مجلّد العمل
CMD> cat <path>             # قراءة ملفّ — عارض قابل للتمرير
CMD> edit <path>            # محرّر نصوص بأسلوب nano (اختصار: ed)
CMD> rm <path>              # حذف ملفّ
CMD> rm -d <dir>            # حذف مجلّد + كل محتوياته (يسأل y/N)
CMD> sdformat [init]        # تهيئة SD إلى FAT32 (تحذير: يمحو كل البيانات)
```

### ملاحظات

- **المسارات نسبية إلى مجلّدك الحالي** (يُضبَط بـ `cd`) — بلا حاجة لـ `/` في البداية. فـ `cat creds.csv` و`edit wordlist.txt` و`rm -d oldtool` تعمل من أي مكان. والمسارات المطلقة (`/apps/...`) مقبولة أيضًا.
- **`cat`**: يحمّل حتى 400 سطر، ويُزيل `\r` الخاص بـ Windows، قابل للتمرير بشريط سماوي. وكرة التتبّع أعلى/أسفل تمرّر.
- **`edit` / `ed`**: محرّر نصوص على الجهاز لملفّات SD (مفيد لتعديل قوائم الكلمات و HTML بوّابات الأَسر والإعدادات ميدانيًّا). وفتح مسار غير موجود يبدأ مخزنًا جديدًا يُكتَب عند أوّل حفظ — وتُنشَأ أي مجلّدات أب مفقودة تلقائيًّا. يحمّل حتى 500 سطر؛ والملفّ الأكبر يُفتَح **للقراءة فقط** فلا يُقتَطع عند الحفظ.
  - **اكتب** للإدراج، و**Backspace** للحذف (اضغط مطوّلًا للتكرار)، و**Enter** يقسّم السطر (مع **مسافة بادئة تلقائية**).
  - **كرة التتبّع** تحرّك المؤشّر (أعلى/أسفل/يمين/يسار، تلتفّ عبر نهايات الأسطر). و**التمرير السريع** يسرّع.
  - **النقر** يفتح **قائمة** الأوامر: حفظ · حفظ باسم · بحث · انتقال لسطر · أعلى · أسفل · تراجع · قصّ سطر · لصق سطر · خروج. (لا يوجد `q` للخروج — `q` حرف عادي — فاخرج عبر القائمة.)
  - **التراجع** يُلغي آخر تغيير (مستوى واحد).
  - الخروج بتغييرات غير محفوظة يطلب: `[s]` حفظ وخروج، `[d]` تجاهل، نقر = إلغاء.
- **`rm`**: يحذف ملفًّا بلا تأكيد. و**`rm -d <dir>`** يزيل مجلّدًا **وكل ما فيه** (تعاوديًّا) — هذا يسأل `y/N` أوّلًا، ويرفض حذف جذر البطاقة أو مجلّد العمل الحالي (اخرج بـ `cd` أوّلًا).
- **`sdformat`**: يطلب تأكيدًا قبل التهيئة. و`sdf init` يهيّئ ويعيد إنشاء بنية المجلّدات كاملةً في خطوة واحدة.
- **الإكمال التلقائي**: يعمل مع `sdls` و`cd` و`cat` و`edit` و`rm` — اضغط `'` لإكمال المسارات.

انظر [تخطيط بطاقة SD]({{ site.baseurl }}/sdcard) للتخطيط الكامل للملفّات.
