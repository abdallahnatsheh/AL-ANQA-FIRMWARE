# اكتشاف الأجهزة

## `netdiscover` / `nd` — اكتشاف المضيفين عبر ARP

يرسل طلبات ARP عبر كامل الشبكة الفرعية المحلّية /24 ويعرض جدولًا بالمضيفين الأحياء مع عنوان IP و MAC. يتطلّب اتصال WiFi فعّالًا.

```
CMD> nd
```

| المفتاح | الإجراء |
|-----|--------|
| `l` / `a` | الصفحة التالية / السابقة |
| `u` | إعادة المسح |
| `q` | الخروج |

تُخزَّن النتائج مؤقتًا — استخدم `show hosts` لعرضها مجدّدًا دون إعادة مسح.

### اختصار الفهرس

بعد تشغيل `nd`، استخدم رقم فهرس المضيف بدل عنوان IP في `portscan` (وكذلك `ps top`) و`ping`:

```
CMD> nd          # [0] 192.168.1.1  [1] 192.168.1.5
CMD> ps top 0    # فحص الأشهر للراوتر
CMD> ps 1 1 1024
```
