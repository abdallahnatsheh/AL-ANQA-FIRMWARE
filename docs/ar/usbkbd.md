# لوحة مفاتيح USB

## `usbkbd` / `uk` — لوحة مفاتيح وفأرة USB HID

يحوّل T-Deck إلى لوحة مفاتيح وفأرة USB HID. يُمرَّر كل مفتاح إلى الحاسوب المتّصل؛ وتتحكّم كرة التتبّع بالمؤشّر.

```
CMD> uk
```

**تكرار Backspace التلقائي:** اضغط Backspace مطوّلًا 1.5 ثانية ← تكرار بنحو 16 حرفًا/ثانية لمدّة تصل إلى ثانيتين، ثم يتوقّف. ونقرة ثانية أثناء التكرار تلغيه.

### سرعة الفأرة

| سرعة التمرير | الخطوة |
|------------|------|
| سريع جدًّا | 20 بكسل |
| سريع | 13 بكسل |
| متوسّط | 8 بكسل |
| بطيء | 5 بكسل |
| نقرة مفردة | 3 بكسل |

### زرّ منتصف كرة التتبّع

| الإجراء | النتيجة |
|--------|--------|
| نقرة < 300 مِلّي ثانية | نقرة يسار |
| ضغط 300 مِلّي ثانية – 1.5 ثانية | نقرة يمين |
| ضغط ≥ 1.5 ثانية | الخروج |
