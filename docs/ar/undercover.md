# الوضع المتخفّي — `notes` / `nt` و `undercover` / `uc`

<span class="label label-yellow">EXP</span>

تطبيق **ملاحظات** حقيقي مدعوم بـ SD يعمل تنكّرًا. فللمُراقِب يبدو الجهاز مجرّد دفتر ملاحظات هاتف — بينما تظلّ أدواتك السلبية تعمل وتسجّل تحته.

---

## الأوامر

```
CMD> notes            # واجهة الملاحظات المستقلّة (بلا وضع صامت)
CMD> undercover       # تنكّر الملاحظات الصامت (الغطاء الحقيقي)
CMD> uc set           # ضبط عبارة مرور خروج سرّية
CMD> uc clear         # إزالة عبارة المرور
CMD> uc status        # عرض عبارة المرور + حالة الغطاء عند الإقلاع
CMD> uc boot on       # الإقلاع مباشرةً إلى الملاحظات (بلا شاشة بدء)
CMD> uc boot off      # استعادة الإقلاع العادي
CMD> uc panic set     # تسليح مفتاح إخفاء فوري (اضغط المفتاح لربطه)
CMD> uc panic off     # تعطيل مفتاح الإخفاء الفوري
```

`notes` يشغّل واجهة الغطاء فقط. أمّا `undercover` فيشغّل الواجهة نفسها **و** يرفع راية التخفّي: فتصمت أصوات الإشعارات ونغمة SSID المخفي، ويبقى شريط حالة AL-ANQA الحقيقي مخفيًّا. وتبقى الأدوات السلبية (`wguard` و`macwatch` و`espchat` …) تعمل وتسجّل إلى SD تحته — تصمت التلميحات المسموعة/المرئية فقط.

---

## استخدام واجهة الملاحظات

| الإجراء | النتيجة |
|--------|--------|
| نقر بطاقة / كرة تتبّع أعلى-أسفل + نقر | فتح ملاحظة |
| نقر سطر داخل ملاحظة | نقل المؤشّر إليه |
| كتابة / Backspace / Enter | تحرير الملاحظة في مكانها |
| كرة التتبّع أعلى / أسفل (في ملاحظة) | تحريك المؤشّر سطرًا |
| كرة التتبّع يسار / يمين (في ملاحظة) | تحريك المؤشّر حرفًا (يلتفّ عبر الأسطر) |
| نقر أيقونة الحفظ | حفظ إلى SD (رسالة: "Saved" أو "No SD") |
| نقر زرّ **+** | ملاحظة جديدة |
| كتابة عبارة المرور السرّية (`uc` فقط) | خروج صامت للأوامر |
| ضغط مفتاح الذعر (`@` افتراضيًّا) | دخول فوري للغطاء من أي مكان |
| `[q]` | خروج — احتياطي فقط، يُعطَّل بمجرّد ضبط عبارة مرور |

تُخزَّن الملاحظات في `/apps/notes/NNN.txt`. و**بلا بطاقة SD** ← تعمل الملاحظات للجلسة (تحرير/تنقّل) لكن لا شيء يبقى بعد إعادة التشغيل — بلا انهيار، فقط بلا حفظ.

---

## الأمان و OPSEC

- تُخزَّن عبارة المرور كـ `SHA-256(salt + phrase)` في `/config/undercover.conf` — **لا** نصّيًّا أبدًا.
- عند الخروج بمطابقة العبارة، لا تُحفَظ الملاحظة المفتوحة عمدًا، فلا تصل ضغطات العبارة (المكتوبة في الملاحظة قبل رصد المطابقة) إلى SD.
- الأخطاء التي تصحّحها بـ Backspace أثناء كتابة العبارة مُعالَجة — فالمطابقة تتتبّع نصّك المُحرَّر.

---

## الغطاء عند الإقلاع

`uc boot on` يُقلع الجهاز **مباشرةً إلى تنكّر الملاحظات** — بلا شاشة بدء AL-ANQA، وبلا وميض أوامر. تُقرَأ SD أوّلًا لتُعرَف الراية قبل أي رسم. وإن ضُبِط PIN قفل أيضًا (`lock new` + `lock boot on`)، فتُطلَق شاشة القفل *بعد* خروج العبارة من الملاحظات — فلا يرى المُراقِب من الإقلاع البارد حتى فتح القفل إلّا الملاحظات.

---

## مفتاح الذعر

`uc panic set` يُسلّح مفتاحًا واحدًا كمُطلِق إخفاء فوري. وضغطه **في أي مكان — حتى منتصف أمر** (مسح، مراقبة، هجوم) — يُدخِل مباشرةً للغطاء؛ اكتب العبارة للعودة. الافتراضي `@` (Sym+P)، اختير لتجنّب التعارض مع استهداف الفهرس مثل `ps #2`. ولا يعمل إلّا بعد ضبط عبارة خروج؛ والمفاتيح المحجوزة (`'`, `q`, مسافة, Enter, Backspace) مرفوضة.

**إيقاظ باللمس** (للمتخفّي فقط) — نقرة تُوقِظ شاشة نصف مُعتِمة؛ ونقرة مزدوجة (خلال 500 مِلّي ثانية) تُوقِظ جهازًا مطفأ الشاشة. والطرفية العادية و`notes` المستقلّ لا يستيقظان باللمس أبدًا.

> **ما زال معلّقًا:** عبارة مرور إكراه/خداع (عبارة ثانية تفتح دفترًا نظيفًا تحت الإكراه) — غير مخطّطة حاليًّا.
