# محاكي NES — `game` / `gm`

<span class="label label-yellow">EXP</span>

شغّل ألعاب NES على T-Deck، مبنيّ على نواة [Anemoia-ESP32](https://github.com/Shim06/Anemoia-ESP32) المضمّنة (GPL-3.0، © Shim06؛ انظر `NOTICES` #20). يدعم **المُخطِّطات (Mappers) 0–4 + 069** — نحو 90% من المكتبة التجارية.

---

## الاستخدام

```
CMD> gm            # فتح مُنتقي مكتبة الألعاب
CMD> gm nova.nes   # تشغيل لعبة مباشرةً من /apps/nes/roms/
```

ضع ملفّات `.nes` في `/apps/nes/roms/` على بطاقة SD. و`gm` المجرّد يفتح **مُنتقي مكتبة** بأسلوب ريترو (كرة التتبّع أو `W`/`S` للتمرير، وشريط تمرير يبيّن الموضع، و`Enter` للتحميل).

---

## التحكّم

| الإدخال | زرّ NES |
|-------|-----------|
| `WASD` / كرة التتبّع | لوحة الاتجاهات |
| `k` | B |
| `l` | A |
| `Space` | Select |
| `Enter` / نقر كرة التتبّع | Start |
| `e` | حفظ الحالة |
| `r` | تحميل الحالة |
| `q` | العودة لمكتبة الألعاب (اضغط ثانيةً للخروج للأوامر) |

- **حفظ الحالات:** فتحة واحدة لكل لعبة في `/apps/nes/states/<CRC32>.state` — `e` يحفظ، و`r` يحمّل (رسالة تأكيد 1.5 ثانية).
- **الصوت** عبر مكبّر I2S؛ و`vol` يضبطه حيًّا.
- **القفل التلقائي مُعطَّل** طوال الجلسة، فلا تُقفَل الشاشة أثناء اللعب (يبقى `lock` الصريح أو مفتاح الذعر عاملًا).

---

## القانون

استخدم فقط الألعاب التي يحقّ لك تشغيلها قانونيًّا. والألعاب مفتوحة المصدر / المنزلية — مثل [Nova the Squirrel](https://github.com/NovaSquirrel/NovaTheSquirrel) (شيفرة GPL-3.0، MMC1) — طريقة قانونية تمامًا لتجربة المحاكي.

---

## تخطيط SD

| المسار | المحتوى |
|------|----------|
| `/apps/nes/roms/<name>.nes` | ألعابك |
| `/apps/nes/states/<CRC32>.state` | حفظ الحالات (واحدة لكل لعبة) |

غير مبنيّ بعد: وحدة تحكّم ثانية، قائمة داخل اللعبة، حفظ SRAM المدعوم بالبطارية.
