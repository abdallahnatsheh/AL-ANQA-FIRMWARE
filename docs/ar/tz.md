# المنطقة الزمنية

## `tz` — ضبط المنطقة الزمنية للجهاز

يضبط المنطقة الزمنية المستخدَمة في ساعة شريط الحالة وطوابع سجلّ جلسات `wguard`. تُحفَظ في NVS — وتبقى بعد إعادة التشغيل.

```
CMD> tz              # فتح مُنتقي القوالب التفاعلي (موصى به)
CMD> tz list         # مثل السابق
CMD> tz +3           # ضبط UTC+3 مباشرةً
CMD> tz -5:30        # ضبط UTC-5:30 مباشرةً
CMD> tz <posix>      # سلسلة POSIX TZ خام (للخبراء)
CMD> tz status       # عرض المنطقة الحالية + الوقت الحالي
```

---

## المُنتقي التفاعلي (موصى به)

تشغيل `tz` بلا وسائط يفتح قائمة قابلة للتمرير من 31 قالبًا. وتُبرَز المنطقة الحالية.

| المفتاح | الإجراء |
|-----|--------|
| كرة التتبّع ↑ / ↓ | تحريك التحديد |
| `w` / `s` | تحريك التحديد (لوحة المفاتيح) |
| Enter | تطبيق المنطقة المحدَّدة |
| `q` | إلغاء — الإبقاء على المنطقة الحالية |

---

## قائمة القوالب

القوالب الـ 31 المدمجة مع سلاسل POSIX الخاصة بها. القيم المعلّمة بـ **(DST)** تتضمّن قواعد توقيت صيفي تلقائية:

| التسمية | إزاحة UTC | سلسلة POSIX |
|-------|-----------|--------------|
| Hawaii | UTC−10 | `HST10` |
| US Pacific | UTC−8 (DST) | `PST8PDT,M3.2.0,M11.1.0` |
| US Eastern | UTC−5 (DST) | `EST5EDT,M3.2.0,M11.1.0` |
| London / Reykjavik | UTC+0 (BST) | `GMT0BST,M3.5.0/1,M10.5.0` |
| Paris / Berlin | UTC+1 (CEST) | `CET-1CEST,M3.5.0,M10.5.0/3` |
| Cairo / South Africa | UTC+2 | `UTC-2` |
| Jerusalem (IST/IDT) | UTC+2 (DST) | `IST-2IDT,M3.4.4/2,M10.5.0/2` |
| Moscow / Istanbul | UTC+3 | `UTC-3` |
| Nairobi / Riyadh | UTC+3 | `UTC-3` |
| Dubai / Baku | UTC+4 | `UTC-4` |
| Karachi / Islamabad | UTC+5 | `UTC-5` |
| New Delhi / Mumbai | UTC+5:30 | `UTC-5:30` |
| Bangkok / Jakarta | UTC+7 | `UTC-7` |
| Beijing / Singapore | UTC+8 | `UTC-8` |
| Tokyo / Seoul | UTC+9 | `UTC-9` |
| Sydney / Melbourne | UTC+10 (DST) | `AEST-10AEDT,M10.1.0,M4.1.0/3` |
| Auckland / Fiji | UTC+12 (DST) | `NZST-12NZDT,M9.5.0,M4.1.0/3` |

*(القائمة الكاملة تحوي 31 قالبًا — راجع المُنتقي على الجهاز.)*

## الإزاحة المباشرة

إن لم تكن منطقتك في القائمة، اضبطها مباشرةً بإزاحة UTC:

```
CMD> tz +3        # UTC+3 (بلا توقيت صيفي)
CMD> tz +5:30     # UTC+5:30 (الهند)
CMD> tz -3:30     # UTC-3:30 (نيوفاوندلاند)
```

تُحوَّل الإزاحات البسيطة إلى سلسلة POSIX صالحة تلقائيًّا. ولا تُطبَّق قواعد توقيت صيفي — فتبقى الساعة على الإزاحة الثابتة طوال العام.

---

## سلسلة POSIX الخام

للتحكّم الكامل بالتوقيت الصيفي، مرّر سلسلة POSIX TZ مباشرةً:

```
CMD> tz EST5EDT,M3.2.0,M11.1.0       # شرق الولايات المتحدة مع DST
CMD> tz CET-1CEST,M3.5.0,M10.5.0/3  # وسط أوروبا مع DST
```

صيغة POSIX TZ: ‏`STD offset DST,start,end` حيث `STD` اختصار المنطقة القياسية، و`offset` ساعات غرب UTC (ملاحظة: **الإشارة معكوسة** — `EST5` يعني UTC−5)، و`DST` اختصار التوقيت الصيفي، و`start/end` قواعد الانتقال `M<month>.<week>.<day>/<time>`.

---

## ملاحظات

- تنطبق المنطقة على **ساعة شريط الحالة** وطوابع **سجلّ جلسات wguard**.
- تُحفَظ في NVS — وتُستعاد تلقائيًّا كل إقلاع.
- `tz status` يعرض سلسلة POSIX النشطة والوقت المحلّي الحالي.
