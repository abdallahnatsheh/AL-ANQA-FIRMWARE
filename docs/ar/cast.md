# التحكم بكروم كاست — `cast` / `ca`
{: .no_toc }

اكتشف أجهزة **Google Cast** على شبكتك وتحكّم بها — Chromecast وGoogle TV وشاشات Nest والتلفزيونات الداعمة للبثّ. شغّل فيديو، ابثّ رابطًا أو عنصرًا محفوظًا، تحكّم بالتشغيل، و**شارك الصور والفيديوهات مباشرةً من بطاقة SD**.

**لأجهزتك فقط.**

## كيف يعمل

يوفّر جهاز Cast قناتَي تحكّم، ويستخدم `cast` كلتيهما:

- **DIAL** (المنفذ `:8008`، HTTP عادي) — يشغّل تطبيقات مثل YouTube. خفيف بلا TLS. هذا مسار «الـ rickroll».
- **Cast v2** (المنفذ `:8009`، TLS + protobuf) — تشغيل حقيقي: تحميل رابط وسائط، تشغيل/إيقاف مؤقّت/إيقاف، مستوى الصوت، وحالة ما يُعرض.

بالنسبة إلى **الملفات المحلية**، لا يستطيع جهاز Cast إلا *الجلب من رابط* — لذا يتحوّل الـ T-Deck مؤقتًا إلى **خادم HTTP صغير** ويمنح الجهاز رابطًا `http://<t-deck-ip>:8123/<file>` ليجلب منه (مع دعم HTTP Range كي يعمل التقديم في الفيديو).

## الاستخدام

يجب أن تكون على نفس شبكة التلفزيون (`cw`).

```
CMD> cw MyWiFi password     # الاتصال بالشبكة
CMD> ca                     # مسح (mDNS) + قائمة تفاعلية
CMD> ca 192.168.1.42        # الانتقال مباشرةً لقائمة جهاز
CMD> ca rickroll 192.168.1.42
CMD> ca share 192.168.1.42 photo.jpg
CMD> ca vol 192.168.1.42 30
```

## الوضع التفاعلي

`ca` (بلا هدف) يمسح عبر mDNS ثم يفتح مُنتقي الأجهزة ← قائمة الإجراءات. كل شيء قابل للتحكّم بلوحة المفاتيح أو الكرة:

- **الكرة ↑/↓** أو **`w` / `s`** — تحريك التحديد
- **نقر** أو **Enter** — تنفيذ
- **`1`–`9`** — اختيار سريع لصفّ بضغطة واحدة
- **`u`** — إعادة المسح · **`q`** — رجوع خطوة

الإجراءات المُدمِّرة (Rickroll، Stop) تطلب تأكيدًا أولًا.

## المحتوى المحفوظ — `/apps/cast/media.csv`

يُنشأ تلقائيًا عند أول استخدام، سطر لكل عنصر بصيغة `name,target`. هدف `http(s)` يُشغَّل عبر **Cast v2**، والمُعرّف المجرّد يشغّل **YouTube عبر DIAL**.

## مشاركة الملفات المحلية — `/apps/cast/share/`

ضع الصور (`.jpg .png .gif .webp .bmp`) والفيديوهات (`.mp4 .webm .m4v`) في `/apps/cast/share`، ثم اختر **مشاركة صورة/فيديو** (أو `ca share <ip> <file>`). يقدّم الـ T-Deck الملف ويجلبه التلفزيون.

## الملفات

| المسار | المحتوى |
|------|----------|
| `/apps/cast/devices.csv` | الأجهزة المكتشفة (`ip,name,model`) |
| `/apps/cast/media.csv` | المحتوى المحفوظ |
| `/apps/cast/share/` | صور/فيديوهات محلية للبثّ |

## حدود صادقة

- **Cast v2 يستخدم TLS** — كلفة ذاكرة DRAM في المصافحة (~30–40 كيلوبايت). إن فشل `:8009` فمسار DIAL يبقى يعمل.
- **مشاركة فيديو تُبقي الـ T-Deck مشغولًا** كخادم حتى تضغط `[q]` (الصور تُجلب مرة واحدة).
- **لا تحويل ترميز** — يجب أن يدعم التلفزيون الترميز أصلًا (mp4/H.264 وwebm يعملان؛ mkv/avi/HEVC غالبًا لا).
- **لأجهزتك وشبكاتك فقط.**
