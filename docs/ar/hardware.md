# T-Deck مقابل T-Deck Plus

يعمل جهازا T-Deck وT-Deck Plus بـ**البرنامج نفسه تمامًا**، والفارق الوحيد في العتاد هو وحدة GPS الموجودة في نسخة Plus. أمّا كل ما عداها — الشاشة، ولوحة المفاتيح، وWiFi، وBluetooth، وUSB، وبطاقة SD، ومكبّر الصوت، والصوت عمومًا — فمتطابق بين الجهازين.

---

## المقارنة

| الميزة | T-Deck | T-Deck Plus |
|---------|:------:|:-----------:|
| الشاشة (320×240 ST7789) | ✅ | ✅ |
| لوحة مفاتيح QWERTY فعلية | ✅ | ✅ |
| WiFi 2.4 GHz | ✅ | ✅ |
| Bluetooth 5 (BLE) | ✅ | ✅ |
| مكبّر صوت I2S مع الصوت | ✅ | ✅ |
| LoRa SX1262 | ✅ | ✅ |
| منفذ microSD | ✅ | ✅ |
| USB-C (للتنزيل ولوظائف USB) | ✅ | ✅ |
| كرة التتبّع (Trackball) | ✅ | ✅ |
| بطارية (مع دائرة شحن) | ✅ | ✅ |
| **وحدة GPS** (L76K / u-blox M10Q) | ✗ | ✅ |

---

## ماذا يُتيح GPS

يؤثّر GPS في أمرين اثنين فقط:

### `trackme` — كشف التتبّع

| القدرة | T-Deck | T-Deck Plus |
|-----------|--------|-------------|
| مسح إعلانات BLE | ✅ | ✅ |
| فترة تعلّم الحالة المرجعية (Baseline) | ✅ | ✅ |
| تقييم السلوك (البوّابة الثانية) | ✅ | ✅ |
| تأكيد مسار الزمن (البوّابة الثالثة) — 5 دقائق فأكثر، وRSSI أعلى من −80 dBm | ✅ | ✅ |
| بوّابة حركة GPS (البوّابة الثالثة) — تحرّك فعلي بمقدار 200 متر | ✗ | ✅ |
| التقاط طلبات فحص WiFi (Probe) | ✗ | ✅ |

على جهاز T-Deck القياسي يبقى الأمر `trackme` عاملًا وقادرًا على بلوغ مستويي التحذير (WARNING) والإنذار (ALERT)؛ غير أنه يعتمد على مسار الزمن في البوّابة الثالثة بدلًا من حركة GPS. أمّا مسار GPS فأسرع وأكثر موثوقية في المواقف التي يكون فيها الجهاز متحرّكًا.

### أوامر GPS

| الأمر | T-Deck | T-Deck Plus |
|---------|--------|-------------|
| `gps on` — تشغيل مهمّة GPS في الخلفية مع الحالة الحيّة | ✗ | ✅ |
| `gps off` — إيقاف مهمّة GPS | ✗ | ✅ |
| `gps test` — قراءة إحداثيات لمرّة واحدة | ✗ | ✅ |

## إعدادات البناء

| | T-Deck | T-Deck Plus |
|--|--------|-------------|
| بيئة PlatformIO | `env:T-Deck` | `env:T-Deck-Plus` |
| راية التصريف (Compile flag) | — | `-DBOARD_TDECK_PLUS=1` |

لا تتحكّم راية `BOARD_TDECK_PLUS` إلا في تهيئة مهمّة GPS وفي مرحلة التقاط طلبات فحص WiFi ضمن `trackme`؛ أمّا بقيّة الشيفرة فتُصرَّف وتعمل بصورة متطابقة على الجهازين.

---

## بدء التشغيل البارد لـ GPS

تحتاج وحدة GPS إلى نحو **أربع دقائق في العراء** للحصول على أوّل تحديد موقع بارد (وهو أوّل تحديد بعد انقطاع التيار أو بعد فترة خمول طويلة). وبمجرّد التقاط الموقع تبقى الوحدة نشطة طوال الجلسة.

**سير العمل المُوصى به لمستخدمي T-Deck Plus:**

```
CMD> gps on      # شغّل مهمّة GPS قبل أي إجراء آخر
```

اتركها تعمل في الخلفية؛ فبحلول انتهائك من مسح WiFi ورغبتك في تشغيل `trackme` يكون تحديد الموقع قد تمّ بالفعل، فيتخطّى `trackme` مرحلة الإحماء الخاصة به ويبدأ فورًا.

وتُظهر أيقونة القمر الصناعي في شريط الحالة الوضعَ الراهن:

| اللون | الدلالة |
|--------|---------|
| رمادي | GPS متوقّف |
| أصفر | جارٍ البحث (لم يُلتقَط الموقع بعد) |
| أخضر | تمّ التقاط الموقع — الإحداثيات متاحة |
